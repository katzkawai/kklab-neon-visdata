# 日本の少子高齢化をデータで視る（1950–2070）

日本国内の公式統計（総務省統計局・厚生労働省・国立社会保障・人口問題研究所・内閣府）をもとに、1950年から2070年までの120年間にわたる日本の少子高齢化を5つのインタラクティブなデータビジュアライゼーションで可視化した静的Webサイトです。

外部フレームワークやバンドラ・API通信を必要としない **Vanilla ES Modules + カスタム SVG** で構築しており、そのまま **GitHub Pages** として公開できます。

> **制作モデル**: 本サイトは **Google Gemini 4 Neon (High)** によって作成されました。

---

## サイト構築方法の概要

### 1. 技術選定とアーキテクチャ方針

| 項目 | 採用技術・方針 | 選定理由 |
| :--- | :--- | :--- |
| **フロントエンド** | HTML5 / CSS3 / Vanilla JavaScript (ES2022 Modules) | ビルド工程・依存パッケージをゼロにし、GitHub Pages での長期運用とメンテナンス性を確保 |
| **描画エンジン** | ネイティブ SVG (`viewBox` ベースレスポンシブ設計) | 解像度に依存しない鮮明な描画、斜線ハッチング等のパターン表現、DOMイベントによる軽量なインタラクションを実現 |
| **データ管理** | 静的 ES モジュール (`js/data/*.js`) に公式統計を格納 | 実行時の外部API依存やCORS・レート制限を排除し、オフラインや静的ホスティング環境でも高速・安定表示 |
| **デザイン設計** | エディトリアル配色・和文タイポグラフィ・`tabular-nums` | 数値の桁ズレを防止し、実績値と将来推計の視覚分離・色覚多様性に配慮したコントラスト設計を徹底 |
| **ホスティング** | GitHub Pages（`.github/workflows/pages.yml` + `.nojekyll`） | `main` ブランチへのプッシュによる自動デプロイ、およびブランチ直公開の両方式に対応 |

### 2. ディレクトリ構成と各ファイルの役割

```text
.

├── css/
│   └── style.css                   # エディトリアルデザインシステム・レスポンシブレイアウト・ツールチップ装飾
├── js/
│   ├── main.js                     # エントリーポイント（全可視化初期化・KPIスパークライン・読了バー・ナビ連動）
│   ├── data/
│   │   ├── population.js           # 1950〜2070年人口推移・年齢3区分・出生高位/低位・5歳階級コホートピラミッド生成
│   │   ├── vitals.js               # 1947〜2024年人口動態統計（出生数・死亡数・合計特殊出生率・歴史的節目注記）
│   │   ├── prefectures.js          # 47都道府県 2024年公式統計（高齢化率・出生率・人口増減率・順位・タイル座標）
│   │   └── international.js        # 主要国の高齢化率推移（1950〜2050年）および倍加年数（7%→14%）
│   └── charts/
│       ├── utils.js                # SVG生成ヘルパ・線形スケール・和文数値整形・色補間・画面端補正ツールチップ
│       ├── pyramid.js              # Chapter 01: 人口ピラミッド（時系列再生・ゴースト比較・コホート強調）
│       ├── structure.js            # Chapter 02: 年齢3区分積み上げ面グラフ＋連動「支え手構造」ピクトグラム
│       ├── vitalsChart.js          # Chapter 03: 出生・死亡「ワニの口」＋合計特殊出生率 上下連動チャート
│       ├── prefectureMap.js        # Chapter 04: 47都道府県等面積タイル地図（14×12グリッド）× 連動4象限散布図
│       └── internationalChart.js   # Chapter 05: 国際高齢化率トラジェクトリ × 倍加年数比較バーチャート
├── .github/workflows/
│   └── pages.yml                   # GitHub Actions による GitHub Pages 自動デプロイ定義
├── .nojekyll                       # GitHub Pages での Jekyll 処理を無効化
└── README.md                       # 本ドキュメント
```

### 3. 各ビジュアライゼーションの実装手法

1. **Chapter 01: 人口ピラミッド（`js/charts/pyramid.js` / `js/data/population.js`）**
   * **コホート要因法キャリブレーション**: 1860〜2070年の歴史的出生数アンカー（団塊の世代・ひのえうま・団塊ジュニア等）と男女別平均寿命推移のロジスティック生存関数から5歳階級（0–4歳〜85–89歳・90歳以上の19階級）を生成し、各年の公式「年齢3区分別人口（年少・生産年齢・老年）」の合計値に厳密一致するようスケーリングしています。
   * **DOM再利用アニメーション**: 36本の棒要素（19階級×男女）を初回に生成し、年次変更時は属性（`x`, `width`, `fill`）のみをCSSトランジション付きで更新することで、1950→2070年の連続再生を滑らかに動作させています。
   * **比較ゴースト＆コホート追跡**: 1970年・2024年・1950年のステップ輪郭パスを重ね描きし、団塊・団塊ジュニア世代が属する階級へ動的にコールアウトを配置します。

2. **Chapter 02: 年齢3区分と「支え手構造」（`js/charts/structure.js`）**
   * **実績と推計の視覚分離**: SVG `<pattern>` による斜線ハッチングと `<clipPath>` を使い、2024年を境界に実績領域と将来推計領域を明確に区別しています。
   * **不確実性の表現**: 社人研「令和5年推計」の出生高位（TFR 1.64）・出生低位（TFR 1.13）の予測幅を半透明バンド＋破線で重畳表示します。
   * **連動ピクトグラム**: グラフ上のホバー座標を線形スケールの逆関数 `xScale.invert()` で年次に変換し、高齢者1人あたりの生産年齢人口比を整数＋端数クリップSVG人型アイコンで即時描画します。

3. **Chapter 03: 出生数・死亡数と合計特殊出生率（`js/charts/vitalsChart.js`）**
   * **交差点分割ポリゴン塗り分け**: 出生数と死亡数の大小関係が逆転する2005〜2007年前後の区間を線形補間で厳密に交点分割し、自然増（ティール）と自然減（クリムゾン）の領域を隙間なく塗り分けています。
   * **上下2段の同期クロスヘア**: 単一SVG内に上段（出生・死亡数）と下段（合計特殊出生率・人口置換水準2.07基準線）を共通X軸で配置し、統合ツールチップで各年の詳細と歴史的背景を表示します。

4. **Chapter 04: 47都道府県タイル地図 × 連動散布図（`js/charts/prefectureMap.js`）**
   * **14×12 等面積カラムマップ**: 通常の日本地図では視認しにくい東京・大阪・沖縄等を北海道と同面積のタイルとして地理的隣接関係を保ちつつ配置し、背景輝度に応じた自動文字色切替（WCAG相対輝度判定）を適用しています。
   * **双方向ブラッシング＆リンキング**: タイル地図・4象限散布図・地方ブロックフィルタ・下部詳細カードが単一状態（`selectedCode`, `hoveredCode`, `region`, `metric`）を共有し、ホバーやクリックで即座に相互ハイライトされます。

5. **Chapter 05: 高齢化スピードの国際比較（`js/charts/internationalChart.js`）**
   * 7%（高齢化社会）・14%（高齢社会）・21%（超高齢社会）の国際基準ラインを備えた推移グラフと、7%→14%倍加年数バーチャートを国別IDで連動強調する構成です。

### 4. ローカルでの動作確認・カスタマイズ手順

#### ローカルプレビュー
ES Modules（`<script type="module">`）を使用しているため、ローカルHTTPサーバー経由で閲覧してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

#### 統計データの更新方法
新しい年次の公式統計（国勢調査・人口推計・人口動態統計等）が公表された際は、以下のファイルを更新するだけで全チャート・KPIスパークライン・順位が自動再計算されます。
* 全国人口・将来推計: `js/data/population.js`（`POPULATION_SERIES`, `BIRTH_COHORT_ANCHORS`）
* 出生数・死亡数・出生率: `js/data/vitals.js`（`VITALS_SERIES`）
* 47都道府県データ: `js/data/prefectures.js`（`PREFECTURES`, `NATIONAL_AVG`）※全国順位は読み込み時に自動算出
* 国際比較データ: `js/data/international.js`

#### データ整合性チェック
Node.js による静的検証コマンド（全モジュールの構文確認および47都道府県座標重複・ピラミッド合計値整合性チェック）：

```bash
node --check js/main.js js/charts/*.js js/data/*.js
```

### 5. GitHub Pages への公開手順

1. 本リポジトリの `main` ブランチへコードをプッシュします。
2. GitHub リポジトリ画面で **Settings → Pages** を開きます。
3. **Build and deployment → Source** で以下のいずれかを選択します：
   * **GitHub Actions**（推奨：同梱の `.github/workflows/pages.yml` が `main` へのプッシュを検知して自動ビルド＆公開）
   * または **Deploy from a branch** → Branch: `main` / Folder: `/ (root)` → **Save**
4. 完了後、`https://<ユーザー名>.github.io/<リポジトリ名>/` にて公開されます。

## 主なデータ出典

* **総務省統計局「国勢調査」**（1950〜2020年・5年ごと）
* **総務省統計局「人口推計」**（2024年10月1日現在・確定値、全国および47都道府県別高齢化率・人口増減率）
* **厚生労働省「人口動態統計」**（1947〜2024年確定数、出生数・死亡数・合計特殊出生率、47都道府県別出生率）
* **国立社会保障・人口問題研究所「日本の将来推計人口（令和5年推計）」**（2025〜2070年、出生中位・高位・低位／死亡中位推計）
* **内閣府「高齢社会白書」**・**国連「World Population Prospects」**（主要国の高齢化率推移および倍加年数）
